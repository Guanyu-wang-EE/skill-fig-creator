# 原生编辑与导出

## 先确定交付要求

默认是对象级可编辑 PPT：标签、节点、模块、连接线、箭头、色条和数据标记分别可改。已有模板时沿用其实际尺寸、字体、配色及编号；独立论文图按参考骨架和最终印刷尺寸确定比例。

使用当前环境支持的原生 PPT 作者工具。已经存在合适构建脚本或图件时进行最小修改，不重写整套绘图系统。计算、数据检查和文件处理可以复用 Python；工具实际支持的原生对象优先于截图。不硬编码另一台机器的运行时、字体、路径或软件版本；先确认本环境已有的必要能力。

## 三种编辑能力不能混称

| 对象 | 能承诺的编辑能力 | 处理 |
|---|---|---|
| PPT 原生形状、文本与路径 | 对象级修改位置、填色、线条及文字 | 核心科学对象使用此类。按组件分组、清楚命名。 |
| 内嵌 SVG | 保留矢量缩放；内部路径未必可在 PPT 编辑 | 需要路径编辑时在实际软件中转换为形状并检查解组结果。 |
| AI 或其他位图 | 整体移动、缩放、裁切或替换 | 不能称为对象级矢量。用户要求全矢量时须重建或换用源矢量。 |

SVG 转形状后检查文字、填色、透明度、遮罩和路径形状。外观与编辑能力同时满足才算成功；不能以导入不报错代替检查。

默认核心科学元素与设备路径都按对象级编辑构建。用户仅要求标签与接线可编辑、并接受图像单体时，可保留相应素材，但交付时说明这个层级。不要先生成无法满足明确要求的位图，再以软件限制为由改变用户的交付形式。

## 定量图保持数据编辑能力

常见柱状、折线、散点或面积结果图优先原生图表，保留相应工作簿或可编辑数据；热力单元和节点电压地图可用数据驱动的原生形状。修改数值后需重新应用原来的颜色映射，不能只改数值文字。

复杂科学图可由 Python/R 生成 SVG/PDF，但整张 SVG 插入 PPT 不会自动变成可编辑坐标轴、图例或数据。用户要求对象级编辑时转为受支持的图表或原生路径并保留文字；用户接受整体矢量图时才采用该交付层级。不承诺图形路径与外部数据具有不存在的自动联动。

## 构建中的实用约束

- 使用作者工具文档中实际支持的字体字段，例如有些 API 使用 `typeface` 而非 `fontFamily`。指定字体后抽查最终 PPT 或 PDF 的实际正文字体，确认没有被主题默认字体或回退字体替代；源码声明和渲染外观相近都不能证明字体已落实。数学辅助字形的字体与正文分别判断。
- 文字保持文本框或可编辑公式，不转成路径。长标签先精简，再调整模块宽度，最后才考虑减小字号。科学变量使用真正的上下标、横线和希腊符号；不要把源码中的 `Actor_i`、`Q_1`、`d_soft` 原样当成论文排版。普通模块名可写为 Actor i；数学表达用支持的富文本或原生公式，并查看组合符号是否错位。
- 数学变量用合适的斜体，运算符、函数名、单位和普通说明词保持正体；不要将混合标签整行斜体。方程换行时保留等号、乘号或其他必要关系，避免两行被读成互不相关的表达式。
- 优先可附着的原生连接线；复杂路线保留为可编辑路径和箭头。连接端点落到真正的目标，不停在无关框线上。
- 箭头头部优先附在线路对象上，避免独立三角形在编辑时漂移。按实际组件分组，不把跨列的无关标题和单元绑成一个模块；在实际 PPT 软件中核对分组与文字仍可选择。
- 全图和模块均可分组，但模块内部对象可分别选择。原生组合缩放不一定同步缩放字体与线宽；嵌入模板后在最终尺寸查看并修正。
- 定量图由真实数据生成；图标不承载没有来源的数值。图表、颜色映射与源数据之间保留必要的复算入口。
- 作者工具的内部像素、PPT 点和导出毫米不能混用。以最终渲染尺寸判断字体与线宽，不只看构建代码里的数值。
- 正式输出与构建目录分开。已有原件先保留，再在候选文件中改动；发布前确认没有覆盖用户期间的新修改。不从过时备份重建并覆盖用户当前文件。

## 适度验证与交付

1. 实际打开或渲染每张受影响的图；依靠 PowerPoint 导出时只关闭本任务打开的文档，不退出用户的应用。记录实际采用的渲染方式，不把其他渲染器的检查称为在 PowerPoint 中检查。
2. 核对本图要求的元素、科学关系、数值、颜色、编辑能力与模板一致性。查看字体、遮挡、箭头方向、裁切、留白及最终尺寸下的设备辨识度，并依 [visual-quality.md](visual-quality.md) 检查主次层级和图元设计。文件结构、导入和碰撞检查只支持各自的有限结论，不能代替视觉判断。
3. 修复实际问题后重看受影响的内容；修改现有多页 PPT 时确认其他页面与编号保留，不增加无关测试。
4. 导出对应 PDF 和高分辨率 PNG。纯矢量图的 PDF 保留文字和线条；含位图时准确说明，不用“矢量 PDF”掩盖其位图元素。

默认正式文件包括一页图件 PPTX、对应 PDF、PNG 预览和简短图注/编辑说明。用户只要求修改模板中的指定页时按其范围交付，不再自动制作另一套汇报。

科学来源、素材来源、必要署名、假设及数据处理规则写入图注、备注或配套说明。内部工具日志、检验记录与失败草稿不放入图面，也不宣称仅凭文件检查已满足期刊投稿要求。
