# 科研图的视觉设计与真实审查

设计布局、制作机制图或用户反馈“粗糙、low、像流程图模板”时读取本文件。它把自然科学科研图常用的主图层级、克制图元与实际尺寸审查方法用于可编辑 PPT，不要求安装其他 skill，也不直接套用某期刊的字号或图数限制。

## 先确定画面，再选择实现

依据内容选择构图：拓扑图以网络为主，方法图以一条主要执行/训练或优化路径为主，结果图以关键数据为主。重复网络、设备或步骤不必有相同视觉权重；辅助更新、目标副本或上下文应帮助主线，而非争夺注意力。用户要求保持旧图结构时保留语义和阅读方向，仍可优化留白、图元尺寸与连接路线。

用几句设计说明确定主视觉、重复模块尺寸与对齐、约两到三个主要字号层级、主/辅线条、色板和必要图元。数学上下标不计入主要字号层级。不另建机械评分表，随后按这个设计构建，而不是让作者工具的默认圆角、填色、字号或现成函数决定外观。

可编辑性和视觉品质是同时需要满足的交付条件。优先原生对象不等于优先粗糙图元；可以使用精细矢量路径、合适源素材和正确的原生公式。需要更换实现方式时保持已经确定的设计与科学含义。

## 常见退化与修正

| 看见的问题 | 常见原因 | 有效修正 |
|---|---|---|
| 每个模块都有一团极小神经元/网线 | 重复装饰细节，没有额外科学信息；节点间距甚至小于节点直径 | 不表达真实架构时省略微型全连接网络，或用一套简洁且可辨识的图元。只有架构本身是研究内容时才画所需层和连接。 |
| 所有标题和模块同样粗大 | 将“增大字体”理解为全部加粗放大 | 区分标题、模块名、变量/注释的层级；用字重与留白突出关键机制。用户要求大字体时先缩短文字，不牺牲主次。 |
| 大空条、套框和长回路线占据画面 | 把参考骨架误当成固定比例，或用框补足空白 | 重复单元用紧凑堆叠、省略号或代表单元；容器仅表达真实分组。按必要内容确定大小，让留白分隔层级。 |
| 原图显得完整，重建稿像随意拼接 | 只带走模块标签，没带走对齐、比例、字重与节奏 | 原图和重建稿同尺寸比较，逐项恢复选定的设计关系；先修整体布局，再抠细节。 |
| 变量像程序代码，横线或上下标浮动 | 普通字符串代替数学排版，组合字形未检查 | 模块名用可读名称；变量用正确富文本或可编辑公式。检查基线、下标、横线及所用字体的字形。 |
| 颜色克制却仍显得乱 | 主、辅线相同，细节密度无层级，读者反复追线 | 先降低无信息细节，建立连线通道和清楚的分叉；强调色只突出关键内容。不要用更多颜色掩盖结构问题。 |
| 自动检查全通过，用户仍认为质量差 | 检查只覆盖文件、越界和文字碰撞 | 保留必要技术检查，另做下面的实际视觉查看；不要把 PASS 等同于美观、科学关系清楚或可发表。 |

表中的情况是修正线索，不是对所有图一律禁用圆点、矩形或重复模块。功能明确、比例恰当的简单几何图元可以构成优秀科研图；精细插画也无法替代良好的信息组织。

## 图元、字体和线条的具体做法

- 重复图元以最终尺寸的实际边界安排间隔；不能仅检查外部模块框不重叠，忽略内部节点挤压和网线变成纹理。
- 模块标题、数学变量和图元各有自己的留白，不把网络图压成盒子底部的狭窄装饰带。泛化图元不暗示真实节点数、层宽或参数量。
- 避免每个元素都有同样突出的边框、粗体和填色。轮廓、浅色背景和强调色承担不同职责；缩成印刷尺寸后仍有主次。
- 相同层级的模块对齐、相近尺寸与一致间距。容器标题占用明确的头部空间，箭头与标题保持距离。
- 区分主数据路径与辅助反馈/参数路径。尽量沿留出的通道走线；折点不能被误读为新的组件，未连接的交叉不能被误读为分叉。
- 论文内已有标题或完整图注时，独立导出图不必再用占据大量空间的演示标题；用户要求标题或模板时保留。

## 用同一稿做三种查看

1. **整图与参考并排**：第一眼是否看到主机制或数据？重复框、长条、装饰细节和留白是否抢占它？沿用参考时是否保留可取的视觉品质？
2. **实际印刷尺寸**：模块名、变量、设备及箭头是否可辨？只在大屏放大后才清楚的细节应精简；不以源代码中的字号代替实际观感。
3. **局部近看**：检查数学字形、圆点间隔、线宽、箭头端点和路径对齐。需要依靠颜色区分时再查看灰度或色觉模拟，不把该项强加给每个小改动。

发现布局主次仍不成立就修布局；发现图元粗糙就修图元；发现字形不对就修排版。不要用又一轮文件验证或增加素材数量代替这些修正。这里只记录影响交付的观察，不生成无用途的评分、完整审计台账或额外审批。

## 实际使用后的教训

一份可编辑算法框架图曾通过文件和碰撞检查，却仍出现重复的微型全连接网格、占据大幅空间的其他单元长条、十余种构建字号及代码式变量标签。问题由构图、图元设计与排版共同造成，文件可打开并未解决它。

将这类反馈用于上面的具体改进，保留“科学内容准确、源对象可编辑”的要求；不要把一次失败扩大成所有图必须添加高级插画、调用更多图片生成、使用固定颜色或重画用户原件的授权。
